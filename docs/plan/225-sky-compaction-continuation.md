## 结论与限制

修正夹具后，这一对真实采样的两版均完成任务；新版恢复减负进入实际请求，首轮输入
减少 16.2%，没有观察到任务约束丢失或重复实施。两版完成轮次相同，不能声称新版
完成率或续跑效率更高；规则逐字完整性仍有上述残留。

仅一个会话边界、每臂一次，环境为重建而非现场完整快照，固定顺序且缓存不对称；
结论只覆盖本模型、本夹具与已观察的五轮续跑，不能推断稳定性。本轮主动重放既定
压缩点，不检验 100 万窗口下是否会自然触发预测溢出，也不拆分两项压缩改动的贡献。

仓库仅记录本计划与 HANDOFF。实验入口、中继、评分辅助脚本、请求回复、会话、临时
工作树和新建实验提交均留本机私有目录。按纯文档规则核对内容、引用、状态、完整差异，
执行 `git diff --check` 和暂存后的 `git diff --cached --check`，不追加代码门禁或 release 检查。
